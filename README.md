# حقوق‌یار 🧮

نرم‌افزار **محاسبه حقوق و دستمزد** با **Node.js** + **اپلیکیشن اندروید** (Capacitor) و **ارسال خودکار فیش حقوقی به ربات بله**.

- سرور: Node.js (Express) — محاسبات، ذخیره‌سازی، API و پنل وب
- اپ اندروید: همان پنل، بسته‌بندی‌شده با Capacitor (APK از GitHub Actions یا Android Studio)
- پیام‌رسان: API بازوی بله (`tapi.bale.ai`) — ارسال فیش، دریافت دستورات کارکنان

> ⚠️ اعداد پیش‌فرض بر اساس مصوبات سال **۱۴۰۵** است (حداقل حقوق، حق مسکن، بن، حق اولاد، معافیت و پله‌های مالیات). هر سال باید از بخش «تنظیمات ← نرخ‌ها» به‌روزرسانی شود. مسئولیت صحت محاسبات و انطباق با بخشنامه‌های جاری با کاربر است.

## امکانات

**محاسبات**

- دوره‌ی شمسی خودکار (`1405-08`)، انتخاب دوره و کپی اقلام از ماه قبل
- حقوق پایه بر مبنای روز کارکرد و کسر غیبت
- اضافه‌کاری (پیش‌فرض ۱٫۴ برابر)، شب‌کاری (۳۵٪)، کار در تعطیل
- حق مسکن، بن خواربار، حق اولاد خودکار (۳ برابر مزد روزانه‌ی حداقل به‌ازای هر فرزند)، پایه سنوات، حق پست، مأموریت معاف از بیمه/مالیات، سایر مزایا
- بیمه‌ی تأمین اجتماعی سهم کارگر ۷٪ با اعمال سقف بیمه (۷ برابر حداقل مزد)، بیمه بیکاری کارفرما
- مالیات بر درآمد حقوق به‌صورت **پله‌ای** با معافیت ماهانه و کسر حق بیمه از مأخذ مالیات
- هزینه‌ی کل کارفرما، هشدارهای اعتبارسنجی، گرد کردن مبالغ

**پنل و ارسال**

- پنل موبایل‌محور فارسی/RTL با فونت Vazirmatn (بدون نیاز به اینترنت برای فونت)
- پیش‌نمایش زنده‌ی فیش هنگام تغییر کارکرد و مزایا
- ارسال فیش به بله: پیش‌نمایش (dry-run)، ارسال تکی، ارسال گروهی، جلوگیری از ارسال تکراری، گزارش ارسال‌ها
- خروجی CSV سازگار با Excel و خروجی متنی فیش‌ها
- رمز عبور پنل، ذخیره‌سازی محلی داده‌ها (JSON) و پشتیبان‌گیری آسان

**ربات بله**

- کارمند: `/link` برای اتصال پرونده، `/payslip` برای دریافت فیش ماه جاری یا هر ماه
- مدیر: `/id`، `/list`، `/summary`، `/send`
- دو روش دریافت پیام: `npm run bot` (long polling، بدون دامنه) یا وب‌هوک HTTPS

## شروع سریع

پیش‌نیاز: Node.js 20 یا بالاتر.

```bash
npm install        # نصب وابستگی‌ها
npm run seed       # (اختیاری) ۵ پرسنل نمونه برای تست
npm start          # http://localhost:3000
```

سپس مرورگر را روی `http://localhost:3000` باز کنید. برای توسعه:

```bash
npm run dev        # ری‌استارت خودکار با تغییر فایل
npm test           # ۶۶ تست محاسبات، تاریخ شمسی، API و بله
```

برای پاک‌کردن داده‌ها: فایل `data/db.json` را حذف کنید (یا `npm run seed -- --force`).

## اتصال به ربات بله

### ۱. ساخت ربات

1. در **بله**، به [`@BotFather`](https://ble.ir/botfather) پیام دهید.
2. `/newbot` را بفرستید، نام و نام کاربری (مثلاً `hoghooghyar_bot`) را تعیین کنید.
3. **توکن** (قالبی مثل `123456789:AAH...`) را کپی کنید.

### ۲. ثبت توکن در برنامه

پنل ← تب **ارسال بله** ← توکن را وارد و «ذخیره» کنید ← «تست اتصال».
برای اطمینان، «شناسه چت مدیر» را وارد کنید و «پیام آزمایشی» بزنید.

برای گرفتن شناسه چت: در بله به ربات پیام دهید و `/id` را بفرستید.

### ۳. اتصال کارکنان

دو راه وجود دارد:

| روش | نحوه |
| --- | --- |
| خودکار توسط کارمند | کارمند به ربات `/link کدپرسنلی کدملی` می‌فرستد (۴ رقم آخر کد ملی). |
| دستی توسط مدیر | در تب «پرسنل»، فیلد «شناسه چت بله» را پر کنید. |

### ۴. دریافت پیام‌های ربات

**روش الف — long polling (ساده، بدون دامنه):**

```bash
npm run bot
```

این دستور در همان مسیر داده‌ی سرور اجرا می‌شود و پیام‌ها را می‌گیرد. برای اجرای دائمی از `systemd`/`pm2` استفاده کنید.

**روش ب — وب‌هوک (نیازمند دامنه و HTTPS):**

1. برنامه را روی دامنه‌ای با HTTPS اجرا کنید.
2. تب «ارسال بله» ← بخش «دریافت پیام‌های ربات» ← آدرس عمومی را وارد و «ثبت وب‌هوک» بزنید.
3. آدرس ساخته‌شده شامل یک secret مشتق‌شده از توکن است: `/api/bale/hook/<secret>`.

> در هر لحظه فقط یکی از دو روش فعال باشد؛ ثبت وب‌هوک، polling را متوقف می‌کند و برعکس.

جزئیات بیشتر: [`docs/bale-setup.md`](docs/bale-setup.md)

## ساخت اپ اندروید (APK)

### روش ۱ — GitHub Actions (بدون نصب ابزار)

با هر push، گردش‌کار `.github/workflows/ci.yml` تست‌ها را اجرا و سپس APK دیباگ می‌سازد:

1. در GitHub به تب **Actions** بروید.
2. اجرای «تست و ساخت APK» را باز کنید.
3. از بخش **Artifacts** فایل `hoghooghyar-debug-apk` را دانلود و `app-debug.apk` را روی گوشی نصب کنید.

### روش ۲ — ساخت محلی

پیش‌نیاز: JDK 21، Android SDK (یا Android Studio).

```bash
npm install
npx cap sync android
cd android
./gradlew assembleDebug        # لینوکس/مک
# gradlew.bat assembleDebug    # ویندوز
```

خروجی: `android/app/build/outputs/apk/debug/app-debug.apk`

برای ساخت نسخه‌ی نهایی امضاشده، در Android Studio مسیر
`Build → Generate Signed Bundle / APK` را بزنید (کلید `keystore` خودتان را بسازید).

اگر بعد از تغییر کد وب، آیکون یا تنظیمات، دوباره `./gradlew` می‌گیرید، ابتدا `npx cap sync android` را اجرا کنید.

## تنظیمات اپ اندروید

اپ اندروید یک **کلاینت** است و برای کار کردن به سرور Node.js نیاز دارد:

1. برنامه را روی کامپیوتر/سرور اجرا کنید (`npm start`).
2. در اپ، آدرس سرور را وارد کنید:
   - روی اینترنت: `https://payroll.example.com`
   - در شبکه‌ی داخلی: `http://192.168.1.10:3000` (گوشی و کامپیوتر در یک وای‌فای)
3. دکمه‌ی «اتصال» را بزنید.

نکته‌ها:

- سرور باید با `HOST=0.0.0.0` اجرا شود (پیش‌فرض همین است) تا از گوشی دیده شود.
- اگر روی سرور رمز پنل گذاشته‌اید، همان رمز را در صفحه‌ی ورود اپ وارد کنید.
- برای اینکه اپ همیشه یک سرور ثابت را باز کند، می‌توانید آدرس را داخل بیلد بگذارید:

  ```json
  // capacitor.config.json
  "server": { "androidScheme": "https", "url": "https://payroll.example.com" }
  ```

  سپس `npx cap sync android` و ساخت دوباره‌ی APK. (در این حالت، اپ نسخه‌ی وبِ روی سرور را نمایش می‌دهد.)

## استقرار روی سرور

### Docker (پیشنهادی)

```bash
cp .env.example .env      # رمز پنل و توکن را تنظیم کنید
docker compose up -d --build
```

داده‌ها در پوشه‌ی `./data` روی میزبان نگه داشته می‌شوند.

### اجرای مستقیم با systemd

```ini
# /etc/systemd/system/hoghooghyar.service
[Unit]
Description=Hoghooghyar Payroll
After=network.target

[Service]
WorkingDirectory=/opt/hoghooghyar
ExecStart=/usr/bin/node src/index.js
Environment=PORT=3000
Environment=PANEL_PASSWORD=یک-رمز-قوی
Environment=PAYROLL_DATA_DIR=/var/lib/hoghooghyar
Restart=always
User=www-data

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now hoghooghyar
```

### Nginx + HTTPS (برای وب‌هوک بله و اپ روی اینترنت)

```nginx
server {
    listen 443 ssl http2;
    server_name payroll.example.com;

    ssl_certificate     /etc/letsencrypt/live/payroll.example.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/payroll.example.com/privkey.pem;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_read_timeout 120s;
    }
}
```

متغیرهای محیطی مهم: `PORT`، `HOST`، `PANEL_PASSWORD`، `BALE_BOT_TOKEN`، `PAYROLL_DATA_DIR`، `CORS_ORIGIN`، `BALE_API_BASE` (نمونه در `.env.example`).

## API

همه‌ی مسیرها زیر `/api` هستند. اگر رمز پنل فعال باشد، هدر `x-panel-password` لازم است.

| متد | مسیر | کار |
| --- | --- | --- |
| GET | `/api/health` | سلامت سرویس و تاریخ امروز |
| GET | `/api/state` | سازمان، تنظیمات، نرخ‌ها، دوره‌ها |
| GET/POST | `/api/employees` | فهرست / افزودن پرسنل |
| GET/PUT/DELETE | `/api/employees/:id` | مشاهده / ویرایش / حذف |
| GET | `/api/period/:key` | محاسبه‌ی کامل دوره (`1405-08`) |
| PUT | `/api/period/:key/input/:employeeId` | ذخیره‌ی اقلام متغیر |
| POST | `/api/period/:key/copy` | کپی اقلام از دوره‌ی دیگر |
| POST | `/api/preview` | پیش‌نمایش فیش بدون ذخیره |
| GET/PUT | `/api/rules` | نرخ‌ها |
| POST | `/api/rules/preset/:year` | اعمال نرخ‌های سال (۱۴۰۴/۱۴۰۵) |
| GET/PUT | `/api/settings` | تنظیمات (توکن ماسک می‌شود) |
| POST | `/api/bale/test` | تست توکن (`getMe`) |
| POST | `/api/bale/test-message` | پیام آزمایشی به مدیر |
| POST | `/api/bale/send` | ارسال فیش‌ها (`dryRun`, `force`, `employeeIds`) |
| GET | `/api/bale/deliveries` | گزارش ارسال‌ها |
| POST | `/api/bale/webhook` | ثبت/حذف وب‌هوک |

| GET | `/api/export/:key.csv` , `.txt` | خروجی اکسل / متن |

نمونه:

```bash

  -H 'Content-Type: application/json' \
```

## فرمول‌ها و نرخ‌ها

خلاصه (جزئیات در [`docs/payroll-formulas.md`](docs/payroll-formulas.md)):

```
مزد روزانه = حقوق پایه ÷ ۳۰
مزد ساعتی = حقوق پایه ÷ ۲۲۰
اضافه‌کاری = ساعت × مزد ساعتی × ۱٫۴
شب‌کاری = ساعت × مزد ساعتی × ۰٫۳۵
حق اولاد = ۳ × مزد روزانه‌ی حداقل × تعداد فرزند (تا سقف ۴)
مأخذ بیمه = مجموع اقلام مشمول (با سقف ۷ × حداقل حقوق ماهانه)
بیمه کارگر = ۷٪ × مأخذ بیمه
درآمد مشمول مالیات = اقلام مشمول مالیات − بیمه کارگر
مالیات = مجموع پله‌ای روی درآمد مشمول
خالص = جمع پرداختی‌ها − (بیمه + مالیات + قسط وام + سایر کسورات)
هزینه کارفرما = خالص ناخالص + بیمه کارفرما (۲۰٪) + بیمه بیکاری (۳٪)
```

**نرخ‌های ۱۴۰۵ (پیش‌فرض):**

| قلم | مبلغ (تومان) |
| --- | --- |
| حداقل حقوق ماهانه | ۱۶٬۶۲۵٬۵۵۰ |
| حق مسکن | ۳٬۰۰۰٬۰۰۰ |
| بن خواربار | ۲٬۲۰۰٬۰۰۰ |
| حق اولاد (هر فرزند) | ۱٬۶۶۲٬۵۵۵ |
| معافیت مالیات ماهانه | ۴۰٬۰۰۰٬۰۰۰ |

پله‌های مالیات ۱۴۰۵: تا ۴۰ میلیون معاف، ۴۰–۸۰ م ۱۰٪، ۸۰–۱۰۰ م ۱۵٪، ۱۰۰–۱۲۰ م ۲۰٪، ۱۲۰–۱۴۰ م ۲۵٪، بالاتر ۳۰٪.

برای سال جدید، در `src/payroll/presets.js` یک ورودی اضافه کنید؛ سپس از تنظیمات پنل «نرخ‌های سال» را اعمال کنید.

## امنیت و پشتیبان‌گیری

- اگر سرور روی اینترنت است، حتماً `PANEL_PASSWORD` بگذارید و HTTPS فعال کنید.
- توکن ربات بله در `data/db.json` ذخیره می‌شود و در API فقط ماسک‌شده برمی‌گردد؛ دسترسی فایل را محدود کنید (`chmod 600`).
- اطلاعات پرسنلی حساس است: پوشه‌ی `data/` در `.gitignore` قرار دارد — آن را کامیت نکنید.
- پشتیبان: کپی از `data/db.json` (یا حجم `./data` در Docker). برای بازگردانی، فایل را جایگزین و سرور را ری‌استارت کنید.
- برای امنیت بیشتر، ربات کارکنان را فقط با `/link` (کد پرسنلی + کد ملی) مجاز کنید و کد ملی را در پرونده‌ها کامل ثبت کنید.
