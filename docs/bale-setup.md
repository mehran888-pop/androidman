# راهنمای اتصال به ربات بله

بله یک API سازگار با Telegram Bot API ارائه می‌دهد:

```
https://tapi.bale.ai/bot<TOKEN>/<METHOD>
```

متدهای استفاده‌شده در این پروژه: `getMe`، `getUpdates`، `sendMessage`، `setWebhook`، `deleteWebhook`، `getWebhookInfo`.

## ۱) ساخت ربات و گرفتن توکن

1. در بله به `@BotFather` پیام دهید (کاربر `botfather@bale.ai`).
2. `/newbot` → نام نمایشی → نام کاربری که با `bot` تمام شود (مثلاً `hoghooghyar_bot`).
3. توکن را ذخیره کنید؛ قالب آن شبیه `123456789:AAHdqTcv...` است.

## ۲) ذخیره در برنامه

پنل ← **ارسال بله** ← توکن را وارد کنید ← **ذخیره** ← **تست اتصال**.

- توکن در `data/db.json` ذخیره می‌شود.
- در پاسخ‌های API فقط نسخه‌ی ماسک‌شده (`1234••••abcd`) برگردانده می‌شود.
- اگر ترجیح می‌دهید توکن در فایل نباشد، `BALE_BOT_TOKEN` را در محیط سرور ست کنید (در این حالت هنوز هم می‌توانید از دکمه‌ی تست استفاده کنید).

## ۳) شناسه‌ی چت مدیر

1. در بله به ربات خودتان پیام دهید: `/id`
2. ربات شناسه‌ی چت شما را برمی‌گرداند (مثلاً `123456789`).
3. همان عدد را در پنل ← «شناسه چت مدیر» وارد و ذخیره کنید.

با این کار دستورات مدیریتی (`/send`، `/summary`، `/list`) برای شما فعال می‌شود و پیام آزمایشی به همین چت ارسال می‌گردد.

> برای گروه‌ها: ربات را به گروه اضافه کنید، یک پیام در گروه بفرستید و `getUpdates` را چک کنید؛ شناسه‌ی گروه معمولاً منفی است (مثل `-1234567890`).

## ۴) اتصال کارکنان

**الف) خودکار با `/link`**

کارمند در بله به ربات می‌فرستد:

```
/link 1001 5678
```

- `1001` کد پرسنلی
- `5678` چهار رقم آخر کد ملی ثبت‌شده در پرونده

اگر کد ملی خالی باشد، فقط کد پرسنلی بررسی می‌شود. برای امنیت بیشتر، کد ملی را کامل در پرونده‌ی کارمند وارد کنید.

**ب) دستی توسط مدیر**

در تب «پرسنل» → ویرایش کارمند → فیلد «شناسه چت بله».

## ۵) دریافت پیام‌ها

### روش A: long polling

```bash
npm run bot
```

- نیازی به دامنه و HTTPS ندارد.
- اگر وب‌هوک از قبل ثبت شده باشد، این دستور آن را حذف می‌کند.
- برای اجرای دائمی:

```ini
# /etc/systemd/system/hoghooghyar-bot.service
[Service]
WorkingDirectory=/opt/hoghooghyar
ExecStart=/usr/bin/node src/bot-poller.js
Environment=PAYROLL_DATA_DIR=/var/lib/hoghooghyar
Environment=BALE_BOT_TOKEN=123456789:AA...
Restart=always
```

### روش B: وب‌هوک

پیش‌نیاز: دامنه‌ی عمومی با HTTPS معتبر (بله به HTTP و گواهی self-signed اعتماد نمی‌کند).

1. در پنل ← «دریافت پیام‌های ربات» ← «وب‌هوک» ← آدرس عمومی سرور را وارد کنید.
2. «ثبت وب‌هوک» را بزنید. آدرس نهایی به شکل زیر ساخته می‌شود:

```
https://your-domain.com/api/bale/hook/<secret>
```

`secret` از هش SHA-256 توکن ربات ساخته می‌شود؛ بدون آن مسیر ۴۰۴ برمی‌گرداند. همچنین اگر بله هدر
`x-telegram-bot-api-secret-token` را بفرستد، مقدار آن بررسی می‌شود.

3. برای حذف: دکمه‌ی «حذف وب‌هوک».

> فقط یکی از دو روش را همزمان استفاده کنید. اگر polling اجرا می‌شود و وب‌هوک ثبت کنید، آپدیت‌ها به وب‌هوک می‌روند و polling خالی می‌ماند.

## ۶) ارسال فیش

- **پیش‌نمایش:** بدون ارسال واقعی، متن فیش و وضعیت هر نفر را نشان می‌دهد.
- **ارسال به همه:** فقط به کسانی که شناسه چت دارند ارسال می‌شود؛ به‌طور پیش‌فرض از ارسال تکراری به همان دوره جلوگیری می‌شود (با سوئیچ «ارسال دوباره» قابل تغییر است).
- **ارسال تکی:** در شیت ویرایش فیش، دکمه‌ی «ارسال فیش این نفر».
- هر تلاش در `deliveries` ذخیره می‌شود و در تب «ارسال بله» قابل مشاهده است.
- بین ارسال‌ها یک تأخیر کوتاه (`sendDelayMs`، پیش‌فرض ۷۰۰ میلی‌ثانیه) برای رعایت محدودیت نرخ اعمال می‌شود.

## ۷) عیب‌یابی

| نشانه | علت احتمالی | راه‌حل |
| --- | --- | --- |
| `401 Unauthorized` | توکن اشتباه/باطل | توکن را از BotFather دوباره بگیرید |
| `chat not found` | کارمند هنوز به ربات پیام نداده یا شناسه اشتباه است | کارمند `/start` بفرستد و `/link` بزند |
| `ارتباط با بله برقرار نشد` | فیلتر/شبکه/پروکسی | از سروری استفاده کنید که به `tapi.bale.ai` دسترسی دارد |
| ربات پاسخ نمی‌دهد | نه polling اجراست نه وب‌هوک | `npm run bot` یا ثبت وب‌هوک |
| فیش خالی/ناقص | اقلام دوره ذخیره نشده | در تب «فیش‌ها» پرونده‌ها را ویرایش و ذخیره کنید |
| خطای `setWebhook` | گواهی SSL یا دامنه | از Let's Encrypt و HTTPS استفاده کنید |
