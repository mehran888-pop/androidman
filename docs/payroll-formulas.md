# فرمول‌ها و مفروضات محاسبه

همه‌ی مبالغ **تومان** است. پیاده‌سازی در `src/payroll/calc.js` و نرخ‌ها در `src/payroll/rules.js` و `src/payroll/presets.js`.

## ورودی‌ها

| فیلد | پیش‌فرض | توضیح |
| --- | --- | --- |
| `daysWorked` | ۳۰ | روز کارکرد |
| `absenceDays` | ۰ | روز غیبت (از کارکرد کم می‌شود) |
| `overtimeHours` | ۰ | ساعت اضافه‌کاری |
| `nightHours` | ۰ | ساعت شب‌کاری |
| `holidayHours` | ۰ | ساعت کار در تعطیل |
| `baseSalary` | ۰ | حقوق پایه‌ی ماهانه |
| `housingAllowance` | خالی = نرخ سازمان | حق مسکن |
| `foodAllowance` | خالی = نرخ سازمان | بن خواربار |
| `children` | ۰ | تعداد فرزند مشمول حق اولاد |
| `seniorityAllowance` , `positionAllowance` , `otherAllowances` | ۰ | مزایای ثابت دیگر |
| `missionAllowance` | ۰ | مأموریت (معاف از بیمه و مالیات) |
| `loanInstallment` , `otherDeductions` | ۰ | کسورات |

## مزد و فوق‌العاده‌ها

```
روز مؤثر        = روز کارکرد − غیبت
مزد روزانه      = حقوق پایه ÷ ۳۰
مزد ساعتی       = حقوق پایه ÷ ساعات ماهانه (۲۲۰)
حقوق پایه دوره  = مزد روزانه × روز مؤثر
اضافه‌کاری      = ساعت × مزد ساعتی × ۱٫۴
شب‌کاری         = ساعت × مزد ساعتی × ۰٫۳۵   (فوق‌العاده، نه مزد کامل)
تعطیل‌کاری      = ساعت × مزد ساعتی × ۱٫۴
```

> اگر ساعت کاری ماهانه را در تنظیمات تغییر دهید (مثلاً ۱۹۲ یا ۱۷۶)، نرخ ساعتی خودکار به‌روز می‌شود.

## مزایای ثابت

```
حق مسکن        = مقدار سازمان یا مقدار اختصاصی کارمند
بن خواربار     = مقدار سازمان یا مقدار اختصاصی کارمند
حق اولاد       = ۳ × (حداقل حقوق ماهانه ÷ ۳۰) × تعداد فرزند (تا سقف ۴)
```

اگر «حق اولاد خودکار» را خاموش کنید، از مقدار `familyAllowancePerChild` استفاده می‌شود.

## بیمه‌ی تأمین اجتماعی

```
مأخذ بیمه = حقوق پایه + اضافه‌کاری + شب‌کاری + تعطیل‌کاری + حق مسکن
           + بن خواربار + سنوات + حق پست + سایر مزایا
           (مأموریت و حق اولاد مشمول بیمه نیستند)

سقف بیمه = ۷ × حداقل حقوق ماهانه
بیمه کارگر = ۷٪ × مأخذ بیمه
بیمه بیکاری کارگر = ۰٪ (قابل تنظیم)
بیمه کارفرما = ۲۰٪ × مأخذ بیمه
بیمه بیکاری کارفرما = ۳٪ × مأخذ بیمه
```

## مالیات بر درآمد حقوق

```
درآمد مشمول = مجموع اقلام مشمول مالیات − بیمه‌ی سهم کارگر
              (بن خواربار، حق اولاد و مأموریت معاف‌اند)
مالیات = محاسبه‌ی پله‌ای روی درآمد مشمول
```

پله‌ها به‌صورت «تا سقف» تعریف می‌شوند و آخرین پله بی‌سقف است:

| درآمد مشمول ماهانه (۱۴۰۵) | نرخ |
| --- | --- |
| تا ۴۰٬۰۰۰٬۰۰۰ | ۰٪ (معاف) |
| ۴۰ تا ۸۰ میلیون | ۱۰٪ |
| ۸۰ تا ۱۰۰ میلیون | ۱۵٪ |
| ۱۰۰ تا ۱۲۰ میلیون | ۲۰٪ |
| ۱۲۰ تا ۱۴۰ میلیون | ۲۵٪ |
| بالاتر از ۱۴۰ میلیون | ۳۰٪ |

هر پله فقط روی **مازاد** همان پله اعمال می‌شود (progressive). پله‌ی اول با نرخ ۰ همان معافیت ماهانه است؛ اگر بخواهید معافیت را جداگانه اعمال کنید، پله‌ی اول را حذف و مقادیر را ویرایش کنید.

## خالص و هزینه‌ی کارفرما

```
جمع کسورات = بیمه + بیمه بیکاری + مالیات + قسط وام + سایر کسورات
خالص       = جمع پرداختی‌ها − جمع کسورات
هزینه کارفرما = جمع پرداختی‌ها + بیمه کارفرما + بیمه بیکاری کارفرما
```

## گرد کردن

همه‌ی اقلام با `roundTo` (پیش‌فرض ۱٬۰۰۰ تومان) گرد می‌شوند؛ برای محاسبات دقیق‌تر آن را صفر کنید.

## مواردی که در این نسخه پیاده نشده است

- عیدی و پاداش پایان سال (می‌توانید در «سایر مزایا» یا «حق پست» وارد کنید)
- سنوات پایان خدمت و بازخرید مرخصی (به‌صورت قلم دستی)
- مالیات سالانه تجمیعی و تسویه‌ی اسفند
- بیمه‌ی تکمیلی و درمان
- کارکرد ساعتی/روزمزد برای کارگران روزمزد

این موارد را می‌توان با اضافه‌کردن قلم در `EARNING_META` و `DEDUCTION_META` (فایل `rules.js`) و یک فیلد جدید توسعه داد.

## به‌روزرسانی سالانه

1. نرخ‌های سال جدید را در `src/payroll/presets.js` اضافه کنید:
   حداقل حقوق، حق مسکن، بن، حق اولاد، معافیت و پله‌ها.
2. در پنل ← تنظیمات ← «نرخ‌های سال» را اعمال کنید.
3. `npm test` را اجرا کنید و با یک فیش نمونه، محاسبات را کنترل کنید.

## سلب مسئولیت

این نرم‌افزار ابزار کمکی است. صحت محاسبات باید با بخشنامه‌های سازمان تأمین اجتماعی و سازمان امور مالیاتی همان سال تطبیق داده شود؛ مسئولیت نهایی با کاربر است.
