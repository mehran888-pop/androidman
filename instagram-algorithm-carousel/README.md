# پست اسلایدی اینستاگرام — «الگوریتم اینستاگرام چطور کار می‌کند؟»

شش اسلاید مستقل (۱۰۰×۰۸۰) + پیش‌نمایش وب به شکل پست واقعی اینستاگرام،
همراه کپشن حرفه‌ای و گروه‌بندی هشتگ‌ها.

## ساختار فایل‌ها

```
instagram-algorithm-carousel/
├── index.html                  پیش‌نمایش پست اسلایدی (HTML + CSS، کاروسل راست‌به‌چپ)
├── styles.css                  استایل اینستاگرامی، تم تارک/روشن، فونت محلی Vazirmatn
├── slides.json                 تمام متن‌های روی اسلایدها (منبع یکتای کپی)
├── build_slides.py             ترکیب آرت + تایپوگرافی فارسیِ واقعی → خروجی نهایی
├── caption.md                  کپشن آماده انتشار + هشتگ‌ها + ALT + چک‌لیست انتشار
├── fonts/                      Vazirmatn (Regular / Medium / SemiBold / Bold)
├── اسلاید-1/ … اسلاید-6/       هر اسلاید در پوشه خودش
│   ├── slide-N.png             آرت خام (تصویر سه‌بعدی بدون متن)
│   ├── slide-N-post.png        نسخه نهایی با متن فارسی — برای آپلود در اینستاگرام
│   └── slide-N-post.jpg        نسخه سبک — همان تصویر، برای پیش‌نمایش وب
```

## پیش‌نمایش

```bash
cd instagram-algorithm-carousel
python3 -m http.server 8000 --bind 0.0.0.0
# سپس  http://localhost:8000/index.html
```

در صفحه می‌توانید: بین اسلایدها بچرخید (فلش‌ها، سوایپ، درگ)، با دوبار ضربه لایک کنید،
حالت «نسخه نهایی / فقط آرت» را عوض کنید، و کپشن یا هشتگ‌ها را با یک کلیک کپی کنید.

## ویرایش متن‌ها

۱. `slides.json` را عوض کنید (ارقام را انگلیسی بنویسید؛ اسکریپت آن‌ها را به ارقام فارسی و
جداکننده هزارگان فارسی تبدیل می‌کند).
۲. `python3 build_slides.py` را اجرا کنید تا PNG و JPG بازسازی شوند.
۳. اگر کپشن را عوض می‌کنید، در `index.html` متغیرهای `CAPTION` / `TAGS_MAIN` / `TAGS_SUB` را
به‌روز کنید و بعد `caption.md` را دوباره بازتولید نمایید.

برای بازتولید `caption.md` از داخل `index.html`:

```bash
python3 - <<'PY'
import re
s=open('index.html',encoding='utf-8').read()
print(re.search(r'const CAPTION =\n`(.*?)`;', s, re.S).group(1))
PY
```

## نکات فنی

- ابعاد ۱۰۸۰×۱۰۸، خروجی PNG بدون فشرده‌سازی مخرب؛ اینستاگرام خودش دوباره فشرده می‌کند.
- تایپوگرافی با `arabic_reshaper` + `python-bidi` و فونت Vazirmatn رندر می‌شود، پس حروف فارسی
  (و نیم‌فاصله‌ها) دقیق‌اند؛ برخلاف متنِ تولیدشده توسط مدل‌های تصویر.
- نیازمندی‌های اسکریپت: `pip install pillow arabic-reshaper python-bidi`
- هندل، نام نمایشی، تعداد لایک و کامنت از آبجکت `CONFIG` در بالای `index.html` عوض می‌شوند.
